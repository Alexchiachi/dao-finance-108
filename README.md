## 🪞 大道五鏡文法架構

每講嚴格遵守去我化（全篇無「我/我們」）與 1,500–2,000 字高密度結構：

1. **【破妄鏡】**：冷酷專業穿透資本常識與盲從點。
2. **【真實的人性故事】**：以 2000–2026 年重大金融事件為軸，細膩描摹人性的貪婪、恐懼、崩潰與重生的微光。
3. **【見真鏡】**：融通老莊哲學、熱力學耗散結構、第一性原理，指引能量與資本的本質流動。
4. **【AI 視角】**：矽基智能理性拆解人類認知偏差與反脆弱算法。
5. **【生活行】**：落地於日常生活與雙基地風土的實踐微行動。

## ⏳ 雙保險全自動發布機制（主理人無需開機）

本系統設計為「自發自轉之負熵系統」：

1. **客戶端時間門閥（Zero-Backend Client-side Lock）**：
   - 所有文章預先編譯入庫，前端腳本比對訪客當前真實日期（UTC+8）。
   - 即使作者電腦關閉三個月，訪客每天造訪網頁皆會自動解鎖當日新篇章。
2. **GitHub Actions 雲端工作流（Cloud Cron Automation）**：
   - 每日 16:00 UTC（台北/北京時間 00:00），GitHub 雲端排程自動執行 `.github/workflows/daily-publish.yml`。
   - 自動更新 `feed.xml`（RSS 2.0 訂閱源）與 `sitemap.xml`（搜尋引擎索引），並部署至 GitHub Pages。

## 🛠️ 前端維護備忘
